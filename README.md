# Data Structures Lab

用 C 實作資料結構，配合課本 *Fundamentals of Data Structures in C*（Horowitz, Sahni, Anderson-Freed）的 Ch1～5。

題目在本機的 judge 上判，這裡只放自己寫的程式。

## 用法

    make list                     # 列出題號
    make submit P=005-brackets    # 交 problems/005-brackets.c

judge 預設在 `~/dev/projects/ds-judge`，放在別的地方就設 `DS_JUDGE=<路徑>`。
